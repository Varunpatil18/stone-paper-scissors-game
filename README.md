# 🪨📄✂️ Stone Paper Scissors Game

An interactive, responsive Stone Paper Scissors (Rock Paper Scissors) web application built using HTML5, CSS3, and modern JavaScript (DOM manipulation and state management).

---

## 🎮 Live Demo

Play the live game here:  
👉 [Stone Paper Scissors Live](https://varunpatil18.github.io/stone-paper-scissors-game/)

---

## 🚀 Features

- Dynamic Match Series: Select a target winning score (5, 10, 20, 25, or 50 points) with automated series-win detection.
- Randomized Computer AI: Real-time algorithmic move generation for the computer opponent.
- Interactive Scoreboard: Instant, live score tracking for both the player and the computer.
- Color-Coded Feedback: Contextual message updates showing round outcomes and match results.
- In-Game Review System: Interactive star rating and feedback input enabling users to submit their thoughts directly on the page.
- Fully Responsive UI: Clean flexbox layout styled for seamless play across desktop and mobile devices.

---

## 🛠️ Tech Stack

- HTML5: Semantic document structure.
- CSS3: Modern dark theme styling, Flexbox layouts, animations, and transitions.
- JavaScript (ES6): DOM selection, event listeners, conditional game loop logic, and dynamic state management.
